# Albert prompt process0.3

An implementation pack for source-bounded, two-host case-preparation podcasts and ten-anchor witness cards. It adds concrete input/permission handoffs, pressure-payoff preservation, complete retrieval checks and bounded reviewer decisions to the existing Toolkit0.2 prompts. The end-user process is prompts and saved files; no API, MCP, code runner or audio tool is required.

Read WF06 for step-by-step placement and file naming. P07 prepares the handoff; T06 connects source evidence to the listening journey; P06 writes; P01 and A02 independently review; P08 edits verified gaps; P09 joins exact checks and stops the loop. A01 checks worker and reviewer instruction compliance when a real problem triggers it. The original Toolkit instructions remain immutable imports, not silently edited files.

| Asset | Purpose | Caller / saved output |
|---|---|---|
| P07-source-consumer-handoff.md | Resolve source scope, permission unit, required input reads and downstream use | W05/source owner → W05-HANDOFF |
| T06-pressure-payoff-review.md | Plan and inspect actual depth, host contribution and retrieval triples | W08 planner, writer, A02 → W08-PLAN and as-built evidence |
| P08-preserve-depth-edit.md | Make a bounded conversational repair with source/coverage checks | W07 editor → new SCRIPT/CLAIMS/KC10/AUTHOR/CHANGE-RECEIPT |
| P09-review-join-stop.md | Join exact independent checks, verify repair, retain negative results and stop | W06/W07 operator → exact revision decision |
| WF06-prompt-process.md | Execute the prompt/file workflow and use the same contracts in all three profiles | Operator → complete saved stage handoffs |
| PROBES.md | Case-free semantic regression inputs | Independent test role → per-probe classifications |

Stable P/A/T/WF and W-stage IDs support search and graph edges. The new shared core maps every added asset to its callers, all three profiles and regenerated Mermaid views. Prompt content remains directly readable Markdown; a generic-asset MCP may later return the same exact files by ID/digest. It is retrieval, not permission to execute agents or access a case store.

This is a task-local development revision. Its exact freeze and evidence receipts state what has been tested, what remains candidate-only and which observed failures motivated it. Written model judgments are not audio, human learning, legal review, universal gold qualification, cross-model testing or Copilot tenant certification. The user authorized this local process revision/test; no global skill or automatic deployment follows.

Rollback selects the retained earlier package and corresponding core binding; old case outputs are never silently rewritten. A failed candidate stays in the private case-study evidence, outside this generic pack. Changing source/view/model/tool/runtime/authority or a prompt invalidates the affected checks. Save new exact receipts instead of claiming an old test covers changed bytes.
