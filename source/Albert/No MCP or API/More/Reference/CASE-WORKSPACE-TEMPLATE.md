# Manual case workspace

Use `11-CASE-STORAGE.md` for the exact directory layout and save/reload procedure. Copy the blank CASE files from this pack into your case workspace, supply real IDs and retain older revisions. CSV relationship fields may use semicolon-separated IDs; IDs must resolve within this case. Empty templates are not evidence. Never treat a graph edge, conflict label or model summary as a source passage.

All case records include case ID and revision. Use stable SOURCE-001, CHUNK-001, NODE-001, EDGE-001 and CONFLICT-001 identifiers within each case. Preserve actual exhibit/page/paragraph identifiers from the source; do not invent page numbers for an unpaginated excerpt. A reviewer may assign paragraph IDs explicitly before extraction.

The operator maintains the current manifest and validates every reference after a change. Duplicate or missing references, mixed cases, omitted qualifiers and missing source text block dependent drafting.
