# C07 — Material revision loop

Input: frozen artifact, C06 findings and operator-approved plan.

Revise only the target artifact. Freeze A1, review it, then freeze A2 after a distinct substantive defect is resolved. Repeat separately for packet and script. A counted cycle needs a changed substantive artifact, resolved finding and no critical regression; cosmetic wording, repeated evaluation or changed prose alone does not count. Maximum five attempts. Stop `UNRESOLVED` after five attempts or any unresolved critical regression. Packet category mapping remains a formal convergence blocker.
