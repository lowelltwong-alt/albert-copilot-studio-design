Input: human-reviewed packet, ledger, approved source spans and revision notes.

Produce a full script with an 8,000–12,000 spoken-word planning target only if the source supports the needed variety. Use chapters: orientation/limits; role and knowledge timeline; exhibits/retrieval; direct preparation; cross themes; impeachment/rehabilitation; varied method-only recall/transfer; concise navigation close. If evidence is insufficient, deliver a shorter honest script plus an explicit gap report. Return one chapter per turn and freeze A0 before C06.
