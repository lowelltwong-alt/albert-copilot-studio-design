# Digital Assets with MCP — AI front door

The independently sendable `Albert-Digital-Assets-1.0.zip` package contains the complete endpoint map, data model, learning loop, tests, provenance and Azure adapter. After extracting that package, open its `AI_FRONT_DOOR.md`.

Use that file as the authoritative evaluation entry point. It explains the DAD-inspired catalog, typed graph, lifecycle checks, signal/noise dispositions, explicit cross-instance learning report, local MCP transports, API backup, and the boundary between tested local behavior and untested tenant deployment.
