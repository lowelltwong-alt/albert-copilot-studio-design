# What is ready, what is not, and how to improve it

This starter is a practical setup and experimentation package. Its native Copilot Studio behavior has not been tested in your tenant. Its prompts do not reliably produce gold-standard podcasts. The owner has accepted that limitation as the starting point for a Innovation-led improvement process.

## Preserve the actual findings

The prior study retained 22 written versions and tested first loops on all four Msimoto witnesses, conditional second loops, four fresh runs and transfer to Kemper and Evans. John's second gain was smaller; Marie's second edit introduced a material method defect. All four fresh repaired assemblies remained held. Kemper's final source review passed, but its final craft review found incomplete applied examination practice; Evans' edit removed useful teaching. These are useful failure specimens, not approved examples to give a witness.

Recurring shortcomings are thin execution despite a detailed plan, incomplete clause-level recall coverage, source/permission/method drift, edits that compress away depth, and reviewers mistaking a checklist or planned feature for a feature actually present. Scores from different rubrics or unmatched judge batches are not a common performance scale.

## This delivery adds

One entrypoint; exact field/prompt placement; four bounded roles; complete runnable stage prompts; a manual identity adapter; a typed file graph; source/permission and craft gates; a synthetic first run; a stop/repair protocol; and versioned experiment records. These additions make implementation and investigation clearer. Local packaging/probe passes do not establish case quality, human learning, audio fidelity, cross-model equivalence or tenant compatibility.

## Practical next sequence

1. operator: complete the synthetic Studio setup probe and save actual UI/model labels, failures and outputs. Repair setup issues before using a real case.
2. Analyst and owner: choose one authorized case/witness, source scope and disclosure basis. Reopen the permitted packet and check at least one source/conflict/exhibit trace.
3. Writer and reviewers: develop one difficult pressure module, then the full episode. Inspect actual teaching, listening quality and source discipline. Keep the first full baseline even if held.
4. Improvement owner: use the bounded baseline/candidate experiment and fresh/transfer tests. Prioritize better use of permitted evidence over more instructions or more rounds.
5. Human listeners and domain reviewer: assess a text read-through for usefulness and truthful practice. Only after text acceptance, generate audio separately and check actual pronunciation, missing speech, timing, pauses and factual changes.
6. Implementation team: adopt a shared store when manual file custody becomes burdensome. Add native child orchestration or MCP/API only after its context, identity, authorization, persistence and duplicate-operation tests pass.

No calendar duration or improvement percentage is promised. A useful short exercise can be accepted as a short exercise; it must not be mislabeled a complete 30-minute rich-case episode. If the case cannot support ten distinct anchors, return fewer with source_depth_shortfall.

## Explicit boundaries

- Prompts cannot guarantee deterministic graph enforcement, immutable storage, complete invalidation, secure context isolation or genuine reviewer independence.
- Manual_revision is an operator-inspected candidate route. Hash_verified mode requires actual computed hashes. Neither a model-invented digest nor a saved filename is proof of content identity.
- The original reference prompts retain their earlier stricter digest language. This starter's declared identity adapter changes only manual matching and labels its result manual_reviewed_candidate; it never claims the older hash-verified qualification.
- Copilot knowledge upload is not output writeback. Default state remains saved files under the operator's custody.
- No audio, live witness handoff, external Innovation message, public release or tenant deployment was performed by assembling this kit.

Original study and attribution records are retained in the surrounding delivery. The send guide identifies them; this generic starter does not contain private case transcripts or raw source material.
