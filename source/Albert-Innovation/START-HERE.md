# Albert

A prompt-only workflow for a source-grounded, two-host preparation transcript and witness preparation card.

1. [Set up the four roles](01-SETUP.md).
2. [Follow the first-run instructions](02-RUN-GUIDE.md), using the exact files in [Prompts](PROMPTS/00-PLACEMENT.md).
3. [Open the workflow diagrams](WORKFLOWS/README.md) in Mermaid, a browser, or Visio.

No custom API, MCP, database or SharePoint setup is needed for this MVP. You save the Markdown packets between roles.

[More](More/README.md) contains the full manual and MCP/API designs, examples, templates, reviews, tests, credits and team assets.

This is a locally checked prototype. The example remains held with documented improvements; tenant testing is pending.
