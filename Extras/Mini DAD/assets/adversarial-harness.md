# Candidate harness for review claims

Bind one baseline and one candidate to the same stated requirement. Run the
aggregate validator, preserve the ordered finding set, and replay the intended
guard in both directions. Record only safe evidence references in a lesson
candidate. Do not include raw prompts, customer data, credentials, local paths,
or full transcripts.

The harness produces evidence for human review. It does not approve, deploy,
or modify an asset.
