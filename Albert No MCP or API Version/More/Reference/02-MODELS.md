# Model choices (checked 2026-09-08)

Use tenant-approved GPT-5.5 Chat as the simplest default when available. It is a cloud model; no API does not mean offline or free. The agent-model documentation is the selector authority: [select an agent model](https://learn.microsoft.com/en-us/microsoft-copilot-studio/authoring-select-agent-model). Prompt model settings are a separate surface and can show experimental choices: [prompt model settings](https://learn.microsoft.com/en-us/microsoft-copilot-studio/prompt-model-settings).

The operator reports seeing `GPT5`, `GPT5.5`, `GPT5.6`, `ClaudeSonnet4.6`, `Sonnet5`, `Opus4.8` and `Opus5` in the standard harness. Preserve those labels as reported, not as independently verified GA availability. Sonnet 4.6 is an optional author; GPT-5.5 Chat is an optional reviewer in a fresh separate conversation. Same-model fresh-session review is useful but proves no independence. GPT5.6, Sonnet5, Opus4.8 and Opus5 remain pilot alternatives pending exact selector, harness and admin validation. A documentation note describing Sonnet 5 as GitHub-harness-only is a reason to test the standard harness, not a reason to claim either side is universally available.
