# Full acceptance checklist

- [ ] H01 rights, audience, role, data scope and operator decision recorded.
- [ ] H02 exact source/exhibit/page/paragraph spans reviewed; summaries never substituted for needed spans.
- [ ] C03 ledger separates source, inference, unknown, method and attributed conflicts.
- [ ] H03 witness limits, affiliations and performance choices reviewed without changing source facts.
- [ ] Packet is complete enough for human review and clearly marked diagnostic while category mapping is unresolved.
- [ ] Packet A0/E0 frozen; A1/E1 and A2/E2 each address distinct substantive defects; each was human reviewed.
- [ ] Script is chaptered, labels production roles, separates spoken words from notes/citations, and has 8,000–12,000 spoken-word planning target only when evidence supports it.
- [ ] Script A0/E0, A1/E1 and A2/E2 were separately reviewed; max five attempts observed; unresolved stop recorded if needed.
- [ ] All eight script dimensions were reviewed: examination readiness; conflicts/impeachment/rehabilitation; role fidelity/truthful answer discipline; timeline/exhibit/source retrieval; unseen transfer/active recall; witness-specific realism; spoken naturalness/read-aloud readiness; navigation/concision/non-repetition.
- [ ] Script diagnostic scores, if used, have dimension evidence and no serious finding; no pre-rounded pass claim.
- [ ] C09 checks names, events, exhibit labels, qualifications, role limits and citations across exact reviewed texts.
- [ ] H05 exact text/audience/use approval recorded manually; H07 download/copy is manual.
- [ ] No gold, signature, hash, grant, server state, evaluator independence or learning proof is claimed.
- [ ] Final delivery contains packet, script chapters, citation notes, source ledger, open questions and manual review record.
