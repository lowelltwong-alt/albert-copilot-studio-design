# Security and privacy

This repository is private because the send-ready MVP archive includes licensed case fixtures. Do not add client records, credentials, API keys, tenant identifiers, access tokens, or raw confidential conversations.

Use environment variables or a managed secret store for runtime credentials. The digital-assets package is a local development component; review authentication, DLP, storage, and tenant policies before connecting it to Azure, Copilot Studio, or Foundry.

Report suspected secrets or privacy incidents privately to the repository owner. Do not open a public issue containing sensitive material.
